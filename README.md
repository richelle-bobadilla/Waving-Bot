# Waving-Bot 🤖 

This project is made for one of the workshops I'm hosting for the UTM Robotics Club!

This repo serves as my journal and progress tracker for building this project.

**StatusL** In Progress 


## Overview
A simple bot who waves at you when you are within a range. They are polite and wait for you to wave at them first. This bot comes with a study timer, reminding you to keep pushing through busy school year!


**ReferenceL** https://caro.io/hibot?utm_source=chatgpt.com



## 🛠️ Hardware Configuration
Here are the hardware/components I am using in my project:
* **Microcontroller:** Arduino Uno
* **Sensors:** HC-SRO4 Ultrasonic sensor, SG90 Micro Servo Motor
